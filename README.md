# Escape House Abuja — Luxury Wellness & Hospitality Platform

A high-fidelity, single-page web platform custom-engineered for an ultra-exclusive luxury sanctuary located in Maitama, Abuja. This platform seamlessly integrates four premium business modules—a luxury spa, boutique hotel apartments, a fine-dining restaurant, and a high-end salon—into a unified, high-converting digital experience.

## 🔗 Live Production Deployment
Experience the fully responsive live platform here: [Escape House Abuja Live](https://ezekielisrael1859.github.io/escape-house/)

## 💎 Design & Engineering Standards
- **Ultra-Premium Aesthetic:** Visual architecture curated to mirror the exclusive, "by invitation only" branding of the physical sanctuary.
- **Unified Brand Presentation:** Streamlined navigation allowing users to explore distinct luxury sub-brands (Spa, Hotel, Restaurant, Salon) seamlessly on a single page.
- **Mobile-First Responsiveness:** Flawless layout fluidly optimized to look stunning on high-end smartphones, tablets, and ultra-wide desktop monitors.

## 🛠️ Technical Stack
- **Frontend Architecture:** Semantic HTML5 framework paired with advanced CSS3 grid configurations, flexbox layers, and clean typographic scaling.
- **Interactivity:** Lightweight native JavaScript ensuring crisp transitions, interactive booking anchors, and responsive menu behavior.
- **Deployment:** Git-managed version control deployed via automated GitHub Pages pipelines.

## 📂 System Breakdown
- `/assets`: Contains core stylesheets, bespoke iconography, and navigation scripts.
- `index.html`: The master interface coordinating premium service spotlights, venue locations, and executive contact points.
